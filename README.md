# sophiadeutschakademie.github.io

소피아 독일어학원(Sophia Deutsch Akademie) GitHub Pages의 맨 위 주소 https://sophiadeutschakademie.github.io/ 입니다.

## 이 저장소가 하는 일

- **첫 화면(`index.html`)**: 맨 위 주소로 들어온 사람에게 SODA Lehrwerk, Goethe 모의고사(SODA-Goethe), telc 모의고사(SODA-TELC)로 가는 길을 보여 줍니다.
- **`robots.txt`**: 검색엔진은 도메인 맨 위의 robots.txt만 읽습니다. `/SODA-Lehrwerk/` 같은 하위 저장소 안의 robots.txt는 읽지 않으므로, 수집을 막을 주소(수강생 전용 학습 포탈, SODA-Lehrwerk로 합친 옛 저장소)와 사이트맵 위치를 여기에 적습니다.
- **`sitemap.xml`**: 첫 화면 주소입니다. 학습 자료 주소는 `SODA-Lehrwerk/sitemap.xml`에 있습니다.
- **사이트 소유 확인**: 네이버 서치어드바이저는 호스트 단위(`https://sophiadeutschakademie.github.io`)로만 등록하므로, 네이버 확인 파일(`naver….html`)이나 확인 태그를 이 저장소에 둡니다. 확인 태그는 `index.html`의 `<!-- site-verification -->` 자리에 넣습니다.

## 웹 주소로 열기

Settings → Pages → Build and deployment에서 Source가 `Deploy from a branch`, Branch가 `main` / `/ (root)`인지 확인합니다.

글꼴은 `/SODA-Lehrwerk/assets/pretendard.css`를 함께 씁니다. SODA-Lehrwerk 저장소 이름이 바뀌면 이 주소도 고칩니다.
